# 常见问题（FAQ）

### **1. 为什么 GFEX 安全？**

GFEX 之所以安全，是因为它采用了 Web3 模式。与传统的存取款方式不同，用户在每次投资时都会直接授权 GFEX 仅访问你投资的金额。这意味着 GFEX 永远不会拥有对你资金的完整、持续访问权限。

### **2. 支持哪些链？**

目前，GFEX 仅支持 Base 链，未来将计划扩展到更多网络。

### **3. 为什么首次访问 GFEX 时，需要断开并重新连接钱包才能切换网络？**

此问题可能与浏览器端的数据（如 Cookie）有关。只需断开钱包，然后重新连接即可解决。

### **4. 为什么我的交易历史不会立即更新？**

由于 GFEX 与区块链集成，交易在历史中显示可能最多延迟 1 分钟，但通常在 3 到 4 秒内即可显示。

### **5. 在 Sepolia 测试网模式下点击“Request Token”后，多长时间可以收到测试网 ETH 和 GUSD？**

在免费体验模式下，点击 “Request Token” 后，测试网 ETH 和 GUSD（GFEX USD）通常会在 **1 分钟内** 发放。这是因为所有代币请求会在每分钟开始时批量处理。

### **6. 如果在交易进行中离开页面，会发生什么？**

如果在交易进行中离开页面，交易仍会在后台继续处理。最终结果将记录在你的历史页面，因为数据直接来源于区块链。\
但我们强烈建议在交易完成前留在页面，以便即时确认并处理任何潜在问题。

**7. 是否有计划支持更多网络？**

是的，我们正在其他流行网络上开发合约。一旦准备就绪，我们会通过官方社交媒体和文档发布更新。

### **8. 如何实现“无存款”交易？**

GFEX 采用 Web3 架构，因此无需存入资金即可开始交易。每次交易时，GFEX 的智能合约仅请求访问投资金额，这也是每次交易前需要确认金额的原因。你的资产始终保留在钱包中，无需存取款。交易结束后，利润将直接分发到你的钱包。



### **9. 我可以使用移动设备在 GFEX 交易吗？**

可以，你可以使用移动设备在 GFEX 进行交易。为了获得最佳体验，我们推荐使用 Base Wallet 或 MetaMask 应用，它们针对 GFEX 交易进行了优化。

### **10. 我在哪里可以获得交易所需的 USDC 和 ETH？**

你可以通过 Base Wallet、MetaMask 或 Phantom 等钱包使用借记卡/信用卡、Apple Pay 或 Google Pay 购买 USDC 和 ETH（取决于钱包和提供商）。大多数主流交易所（包括 Coinbase）也支持 USDC 和 ETH 购买。如果你已使用本地交易所，也可以在交易所购买 ETH 或 USDC 并提现到你的钱包，记得选择 Base 网络。如果交易所不支持 Base 上的 ETH 或 USDC，可以使用桥或兑换平台将资产转换为 Base 链上的 ETH 或 USDC。

### **11. 什么是 Achievement NFT，我如何获得？**

Achievement NFT 是独特的数字收藏品，当你在 GFEX 达到特定交易里程碑时解锁。这些 NFT 会在你完成某些成就（如连续获胜、交易量目标或特别活动参与）后自动铸造到你的钱包。

### **12. Achievement NFT 除了收藏还有其他用途吗？**

Achievement NFT 可能在 GFEX 生态系统中提供额外福利，包括访问专属功能、提高推荐奖励或特殊交易机会。不同等级的 NFT 代表不同的交易成就水平。

### **13. 我可以转让或交易我的 Achievement NFT 吗？**

可以，Achievement NFT 遵循标准 NFT 协议，因此你可以在兼容的 NFT 市场上转让、交易或展示它们。但与特定成就相关的任何福利可能仅适用于原始获得者。

### **14. 什么是 Bridge 功能，它将支持哪些网络？**

Bridge 功能允许你在 GFEX 内无缝地在不同区块链网络之间转移资产。我们将从流行网络开始，具体支持的链会在官方渠道公布。

### **15. 使用 Bridge 需要支付费用吗？**

Bridge 交易涉及源链和目标链的网络 Gas 费用，以及任何桥协议费用。GFEX 会在你确认交易前显示所有相关费用。

### **16. 跨链转账安全吗？如果 Bridge 交易失败会怎样？**

GFEX 使用安全可靠的桥协议。如果桥交易失败，你的资产依然安全，会成功完成或返回到原始钱包。桥交易也会在链上记录，保证完全透明。
