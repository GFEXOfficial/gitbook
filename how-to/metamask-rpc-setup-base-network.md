# Metamask RPC Setup (Base Network)

### **1**. **Click the network selector in the top-left corner.**

<figure><img src="../.gitbook/assets/1 (1).PNG" alt=""><figcaption></figcaption></figure>



## 2. Click 'Add a custom network' button at the bottom.

<figure><img src="../.gitbook/assets/2 (1).PNG" alt=""><figcaption></figcaption></figure>



### 3. **Enter the following information in each field.**

* **Network Name:** Base Mainnet
* **RPC URL:** [https://mainnet.base.org](https://mainnet.base.org)
* **Chain ID:** 8453
* **Currency Symbol:** ETH
* **Block Explorer:** [https://basescan.org](https://basescan.org)

<figure><img src="../.gitbook/assets/3 (2).PNG" alt=""><figcaption></figcaption></figure>

Enter the provided information, then click **"Save."**



## 4. You're all set!

<figure><img src="../.gitbook/assets/4 (1).PNG" alt=""><figcaption></figcaption></figure>
