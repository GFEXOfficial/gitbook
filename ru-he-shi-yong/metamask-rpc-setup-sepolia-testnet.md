# Metamask RPC Setup (Sepolia Testnet)

### **1**. **Click the network selector in the top-left corner.**

<figure><img src="../.gitbook/assets/1 (1).PNG" alt=""><figcaption></figcaption></figure>



### 2. Click 'Add a custom network' button at the bottom.

<figure><img src="../.gitbook/assets/2 (1).PNG" alt=""><figcaption></figcaption></figure>



### 3. **Enter the following information in each field.**

* **Network Name:** Base Sepolia Testnet
* **RPC URL:** sepolia.base.org
* **Chain ID:** 84532
* **Currency Symbol:** ETH
* **Block Explorer:** base-sepolia.blockscout.com

<figure><img src="../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>

Enter the provided information, then click **"Save."**



### 4. You're all set!

<figure><img src="../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
