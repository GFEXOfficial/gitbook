# 适用于 GFEX 的 Web3 钱包与加密资产



如果你完全没有使用 Web3 钱包（如 MetaMask）的经验，请先参考[这篇文章](https://x.com/GFEXOFFICIAL/status/1873325276031226359)。

***

### <mark style="color:red;">0. 将 Base 网络添加到你的 MetaMask 钱包</mark>

1. 打开 MetaMask，点击左上角的网络选择器。
2. 选择“Add Network（添加网络）”，然后输入以下信息：

* **Network Name（网络名称）：** Base Mainnet
* **RPC URL：** [https://mainnet.base.org](https://mainnet.base.org)
* **Chain ID：** 8453
* **Currency Symbol（货币符号）：** ETH
* **Block Explorer（区块浏览器）：** [https://basescan.org](https://basescan.org)

输入完成后，你的钱包已经成功添加 Base 网络！\
如需分步图解说明，请参考[这篇文章](metamask-rpc-she-zhi-base-wang-luo.md)。

***

### **1. ETH（Base）和 USDC**

在 GFEX 上进行交易，你需要持有 Base 网络的原生代币 **ETH（Base）** 以支付 Gas 费用。\
Base 网络的 Gas 费用非常低，通常每笔交易仅约 **$0.01**。

接下来，你需要在 Base 网络获取 **USDC**，并与 ETH 一同存放在同一个钱包中。\
当你的钱包中同时准备好 ETH 和 USDC 时，你就可以开始在 GFEX 上进行投资了。

***

### **2. 获取 USDC 和 ETH（Base）的方式**

你可以通过多家交易所获取 ETH（Base）和 USDC，例如：

* Coinbase
* Bybit
* Binance
* OKX
* Kraken
* KuCoin
* 以及其他交易所

购买完成后，将资产 **提现到你的 Web3 钱包（MetaMask）并选择 Base 网络**。\
完成这些步骤后，你的钱包就已准备就绪。

***

### **3. 如何将 Ethereum 或其他链上的资产转换到 Base 网络**

如果你想将以太坊链（或其他链）上的 ETH 或 USDC 转换至 Base 网络，可以选择以下几种便捷方式：

* [**ChangeNOW.io**](https://changenow.app.link/referral?link_id=1cfdeec004b5d7)**：** 支持快速跨链兑换 ETH 和 USDC 等多种资产。
* [**Magic Eden Wallet**](https://wallet.magiceden.io/)**：** 提供用户友好的移动应用，可轻松将 ETH 从以太坊转换到 Base。
* [**Jumper.Exchange**](https://jumper.exchange/)**：** 支持在以太坊与 Base 之间桥接 ETH 和 USDC。
* [**Defiway**](https://defiway.com/)**：** 提供跨链桥服务，可将 ETH 与 USDC 从 Ethereum 转移至 Base。
* [**RocketX Exchange**](https://www.rocketx.exchange/)**：** 支持在 Base 网络上交换和转换 ETH。
* [**Superbridge**](https://superbridge.app/)**：** Base 官方文档中提到的跨链桥，可将 ETH 等资产从 Ethereum 转移到 Base。

这些服务都能帮助你轻松将资产迁移到 Base 链。\
使用任一平台时，请务必：

* 连接你的钱包
* 选择正确的网络与代币
* 仔细检查交易详情后再确认

建议你先用小额测试，确认操作无误后再进行大额转移。

当你的钱包准备好在 GFEX 上投资后，请继续前往下一页阅读详细教程，然后再开始交易。

***

### 4. 使用 GFEX 的 Swap 与 Bridge（跨链）

GFEX 提供由官方合作伙伴 **WOWMAX** 支持的 **Swap** 和 **Bridge** 功能。

**Swap** 功能允许用户在 Base 网络上将任意资产兑换为其他受支持的 Base 网络资产。\
**Bridge（跨链）** 功能允许用户将 Base 网络上的资产转换为目标链上的对应资产，从而转移至其他受支持的区块链。

通过这些功能，用户可以将其在 Base 网络上持有的任何资产无缝转换为 **ETH（Base）** 或 **USDC**，并用于在 GFEX 上进行交易。
